# Blog Preview Card

A responsive blog preview card built as part of a Frontend Mentor challenge.

![Project preview](./preview.jpg)

## Overview

This project recreates a blog preview card using semantic HTML and responsive CSS. The layout adapts to desktop and mobile screens while preserving the visual style of the original design.

## Features

- Responsive layout
- Semantic HTML structure
- Local variable font with `@font-face`
- Responsive typography using `clamp()`
- Hover and keyboard focus states
- Accessible image descriptions

## Built with

- HTML5
- CSS3
- Flexbox
- CSS custom font loading
- Mobile-first responsive design

## What I learned

During this project, I practiced creating semantic HTML, centering content with Flexbox, loading a local variable font, building responsive typography with `clamp()`, and adding accessible interactive states.
